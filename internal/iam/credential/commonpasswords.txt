# The passwords this engine refuses, on top of the twelve-character minimum.
#
# NOT A TOP-TEN-THOUSAND CORPUS, and strength.go argues why at length: behind a
# twelve-character floor almost none of such a list is reachable, because those
# lists are ranked by observed frequency and human-chosen passwords cluster at
# six to ten characters. What survives the floor is a small set of FAMILIES,
# and that is what this file holds -- a word with padding after it, a walk
# along the keyboard, a repeated block, and the handful of phrases that became
# common by being famous.
#
# EVERY ENTRY IS COMPARED IN FOLDED FORM: lower-cased, trimmed, and with the
# substitutions everybody makes undone (4 to a, 3 to e, 1 to i, 0 to o, 5 to s,
# @ to a, $ to s, 7 to t). So one entry catches every spelling of its family --
# `password1234`, `P@ssw0rd1234` and `p4$$w0rd1234` are one string here, which
# is what lets this file be hundreds of lines rather than thousands.
#
# TWO RULES FOR AN ENTRY. Write it in PLAIN LETTERS, because an entry written
# in leetspeak folds onto its own plain spelling and adds nothing. And do not
# add one shorter than twelve characters: the floor already refuses it, and a
# line that can never match reads exactly like one that does.
#
# Blank lines and lines beginning with # are ignored.
